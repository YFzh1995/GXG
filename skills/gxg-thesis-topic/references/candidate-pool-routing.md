# IPO候选公司池接入规范

## 定位

Skill 自带三份候选与状态资产：

- `assets/candidate-pool.csv`：上交所、深交所和港股候选公司池；
- `assets/candidate-pool-bse-2023-2025.csv`：北交所候选公司池；
- `assets/company-register.csv`：已经建立公司发现库的公司登记表。

它们与模型已有的公司、行业和商业模式知识共同用于加速“学生没有指定公司”或“学生只给出行业/职业方向”时的首轮案例筛选，不是最终的上市资格证明，也不是公司事实库。模型知识可以形成筛选假设，面向学生展示前必须用当前公开来源核验公司身份、业务和资料成熟度。

候选池与登记表是可选的加速资产，不是必需输入：发布包未携带 assets、文件过期或读取失败时，Skill 仍应基于模型已有知识与当前公开来源核验完成初筛与选题，assets 缺失不得阻断工作流。

## 当前范围

原论文 Skill 的名单范围是2023—2025年首次上市公司：

- A股：上交所（`SSE`）和深交所（`SZSE`），包括主板、科创板和创业板；
- 北交所：北京证券交易所（`BSE`），纳入2023—2025年向不特定合格投资者公开发行并上市的公司；
- 港股：香港联交所主板（`HKEX`），可包含首次H股上市的A+H公司；
- 排除：北交所存量精选层平移但在目标期间没有新的公开发行上市、独立新三板挂牌、港股GEM、SPAC、REIT、介绍上市、转板、借壳/反向收购、仅二次上市及官方资料不足的公司。

截至2026-08-24，Skill 自带的非北交所候选池有545条记录：SSE 177条、SZSE 226条、HKEX 142条；北交所候选池有126条：2023年77条、2024年23条、2025年26条。合并快照为671条。数量是当前快照，不应写死为永久数据；每次使用前应重新读取并统计。

北交所资产中的2023—2024年记录按北交所代码映射和IPO发行上市资料交叉整理；2025年记录补入全年26家口径，并单独核验世昌股份（`920022`）的上市日期。它仍然只是选题初筛索引，正式建库前必须重新回到北交所或法定披露文件逐家公司确认。

## 使用顺序

1. 读取 Skill 自带的`assets/candidate-pool.csv`和`assets/candidate-pool-bse-2023-2025.csv`，结合模型已有知识，按学生的目标就业城市、目标就业行业、目标就业公司、目标就业岗位、专业适配和上市年度形成初筛。
2. 读取 Skill 自带的`assets/company-register.csv`作为Kent实验工作区的研究进度提示。仅在当前任务确实复用同一工作区时避免重复建库；在其他工作区或面向新学生时，已建库公司仍可成为候选，不得仅因登记表中已有记录而排除。
3. 优先选择资料成熟、已经具备IPO文件和连续年报的公司；候选池中的来源链接只用于定位，不替代官方资料核验。
4. 对目标公司或候选公司核验首次交易日、交易所、板块、是否属于原论文 Skill 范围，并确认不是二次上市或其他排除类型。北交所公司还要核验公开发行上市公告、招股说明书和代码切换情况；候选池使用当前920代码时，检索IPO文件要同时尝试备注中的发行/旧代码。
5. 只有完成公司发现库的来源登记和事实卡后，才生成论文题目。候选池不能直接产生题目。

## 选择模式

- 学生指定公司：不从池中替换目标公司；先核验目标公司，资料不足时再从池中寻找可比案例。
- 学生指定行业或职业方向但没有指定公司：在池中筛选候选，再按资料成熟度、专业适配、真实商业问题和职业关联排序；对学生一次展示3家公司，供单选。
- 学生没有公司和方向：完成最低信息采集后，同样一次展示3家公司；不能替学生直接定案。

## 面向学生的案例选择循环

这是用户选定公司前的固定交互，不是一次性把候选池全部展示出来，也不是在学生没有选择时直接进入选题。

1. 每一批固定推荐3家公司。每家公司至少写1—2句话，说明主营业务/商业模式、行业或制造属性、上市与公开资料条件，以及为什么和学生的专业或职业方向相关；只使用已经核验的事实，不把内部筛选字段直接展示给学生。
2. 三家公司之后提供单选项：`选择A`、`选择B`、`选择C`、`三家都不满意，再推荐三个`。如果平台支持结构化选择，使用单选；如果不支持，使用同样的编号格式。
3. 学生选择“都不满意”时，再筛选并推荐下一批3家公司；保留上一批结果和不满意状态，不能把下一批与上一批混成无序长名单，也不能重复已展示公司。连续两批都不满意时先询问1—3个排除原因或新偏好，再决定是否继续推荐。
4. 学生选定一家公司后，记录公司全称、证券代码/市场和选择批次，停止推荐循环，才进入公司核验、事实基础和论文选题生成。
5. 在学生选定公司之前，不生成该公司的事实卡、候选论文题目或题目横向比较；可以回答候选公司的基本情况，但不能把未选公司当成已确认案例。

## 维护边界

候选池是可更新的 Skill 资产。年度更新时应分别补充SSE、SZSE、BSE和HKEX新增上市公司，复核来源链接、去重代码和公司名称，并重新核验市场范围。北交所不能只按代码或上市日期机械纳入：需要确认是否完成公开发行并上市、是否属于精选层平移、IPO文件和年报链是否足够，以及旧代码/920代码能否互相追溯。北交所附带资产是实验快照，后续年度更新时应重新从北交所公开发行信息披露和公司官方文件复核。第三方链接只能定位，不能升级为事实证据。

如果当前工作区同时存在项目目录下的更新版候选池，先比较文件更新时间、行数和来源状态，再决定是否刷新 Skill 资产；不能静默把两个版本拼接。刷新后必须重新去重并更新快照统计。
