# 原论文 Skill 的选题生成流程

本文件保留原论文写作 Skill 的核心方法，不把选题简化成标题生成。

## 1. 先建公司发现库

公司不是题目。对每家公司保存：

- 官方 IPO 文件和连续年度报告；
- 来源登记和报告期间；
- 文本或页码定位；
- 事实卡；
- 全部候选题；
- 本科、专硕、学硕和MBA四类培养类型评价；
- 文献预检计划；
- 题目版本与选择记录。

选中一个题目后，公司发现库仍然保留其他候选题，不删除或覆盖。

公司阶段状态：

`company-created → sources-building → facts-ready → topics-generated → levels-assessed → literature-precheck → discovery-ready`

## 2. 事实卡

每条事实至少记录：

`Fact_ID｜命题｜数据或原文摘要｜Source_ID｜PDF页｜期间｜单位｜事实/公司解释/研究者计算/研究者推断｜素材维度｜相关专业｜待核验`

事实发现重点包括：

- 指标方向变化；
- 收入、毛利、现金流、客户、渠道、产能或融资之间的背离；
- IPO前后或不同披露版本的差异；
- 招股书风险/承诺与后续表现的落差；
- 问询问题的延续或转化；
- 同口径同行分化；
- 商业模式和会计口径之间的张力。

## 3. 候选题生成

通常生成3—6个候选题；事实维度充分且题目有实质差异时可增加到8个，不足时少报且不凑数。候选题整体尽量覆盖多个素材维度，但每一个具体题目只围绕一个明确现象或一组紧密相关指标。

本科题通常使用1—3个核心指标，单公司或最多一个严格可比同行。专硕题必须形成真实决策闭环；学硕题必须有系统文献、理论问题和竞争解释。技术难度、篇幅和术语数量不能单独证明硕士层次。

题目应类似：

- 订阅化、合同负债与经营现金流之间的关系；
- 毛利率改善为何没有同步降低外部流量成本压力；
- Robotaxi收入占比变化与综合毛利率变动；
- 高外销结构下汇率波动与利润传导。

避免：

- 某公司经营问题及对策；
- 某公司财务状况全面分析；
- 某公司发展战略研究。

## 4. 去重与六项排序

排序前比较候选题的核心现象、可能机制、核心指标和最低证据集。四项中有三项高度重合时，原则上视为同一题簇，只保留范围更窄、证据更强、与目标培养类型更匹配的一题；另一个只有在研究问题和结论边界确实不同的情况下保留。

每题按`references/level-calibration.md`的锚点对以下六项各0—2分进行内部排序：

1. 范围是否集中；
2. 资料是否足够；
3. 数据是否可复算；
4. 真实现象是否明确；
5. 解释证据是否成立；
6. 教学和商业价值是否清楚。

排序只在最终门槛相同的题目之间进行，不能抵消`repair`、`pending-literature`或`fail`状态。

## 5. 详细题卡字段

每题都要解释：

- 研究现象；
- 核心问题；
- 核心指标；
- 解释角度；
- 最低资料集；
- 需要补充的资料；
- 新意；
- 主要风险；
- 不能写的结论；
- 适配专业；
- 适合的培养类型、证据上限和按优秀标准完成时的要求；
- 学生需要掌握的知识；
- 预计工作量和答辩负担；
- 退出或缩题条件；
- 与目标就业城市、就业行业、就业公司或就业岗位的职业关联。

## 6. 选择门槛

按`references/level-calibration.md`分别计算培养类型、事实证据、数据复算、文献和最终门槛。只有最终门槛为`pass`，题目才可以被描述为“首选”“推荐”“可行”或进入下一阶段。`repair`必须写成“需重构”；`pending-literature`必须写成“待文献验证”；`fail`不得推荐为当前正式题目。
