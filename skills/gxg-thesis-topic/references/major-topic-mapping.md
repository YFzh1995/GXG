# 专业与素材维度映射

专业决定先看哪些事实、使用什么框架，不改变培养类型硬门槛。

| 专业或方向 | 首选素材维度 | 常见题目方向 |
|---|---|---|
| 会计学 | 财务与会计、治理与披露 | 收入确认、合同负债、减值、非GAAP口径、披露差异 |
| 财务管理 | 财务与会计、经营与规模、市场与渠道 | 现金流、资本结构、募投效益、盈利与成本压力 |
| 审计学 | 财务与会计、治理与披露、监管 | 关键审计事项、问询函、审计风险、处罚路径 |
| 金融/投资/资产评估 | 财务与会计、行业与竞争、市场与渠道 | IPO定价、估值、融资结构、公允价值、商誉 |
| 工商管理/MBA | 商业模式、治理与披露、行业与竞争 | 平台模式、战略取舍、资源配置、并购整合 |
| 市场营销/电子商务 | 市场与渠道、经营与规模、商业模式 | 获客成本、渠道结构、补贴、留存、平台佣金 |
| 人力资源管理 | 人力与激励、治理与披露 | 股权激励、薪酬、员工结构、绩效指标 |
| 国际商务/国际经贸 | 市场与渠道、行业与竞争、监管 | 海外收入、汇率、跨境业务、海外治理 |
| 经济学/经济统计 | 行业与竞争、经营与规模、财务与会计 | 市场结构、规模效率、集中度、行业分化 |
| 供应链/物流管理 | 供应链与采购、经营与规模、财务与会计 | 供应商集中度、库存、采购成本、供应链风险 |
| 信息管理 | 商业模式、经营与规模、治理与披露 | 平台治理、数据资产、信息披露、数字化效率 |

同一事实可以服务多个专业，但研究问题、指标、分析框架和文献角色必须随专业改变，不能只改标题。
