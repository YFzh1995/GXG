# GXG · 观星哥的财经职场工具箱

> 把你真实的工作、面试和论文问题，变成能直接用的答案和判断。

GXG（GuanXingGe）是观星哥为**财经职场人**和**财经类学生**做的一套「AI 技能包」。它不需要你懂代码——装进你常用的 AI 助手后，你只要像跟人聊天一样用大白话提问，它就会像一位懂行、耐心、还知道行业水深水浅的**校外导师**，帮你把问题一步步理清楚。

**当前版本：v1.3.0**

## 这是给谁用的

| 你是…… | 你能得到什么 |
|---|---|
| **商科 / 财经 / 经管类毕业生、MBA 学生** | 帮你找到「能写、能答辩、还能为找工作加分」的论文题目 |
| **正在求职、跳槽或准备面试的财经人** | 判断自己适不适合某个岗位，并把面试练熟 |
| **想看懂公司和商业逻辑的财务人** | 用真实上市公司案例，看懂一家公司靠什么赚钱 |
| **过去买过观星哥服务的老朋友** | 把你已有的咨询、简历资料接着用，让结果更贴合本人 |

## 它能帮你做的四件事

### 1. 判断「我适不适合这个岗位」—— 人岗匹配

- **给谁用**：正在看岗位、准备跳槽或第一次找工作的财经人。
- **能做什么**：把你的简历和目标岗位的要求放进来，它一项一项对照，告诉你哪些匹配、哪些有差距、面试时最可能被问什么，以及你需要补充什么证据。
- **怎么用**：在对话里说「**分析我和这个岗位的匹配度**」，附上你的简历和岗位介绍（JD）。

### 2. 准备一场真实面试 —— 面试辅导

- **给谁用**：面试临近、想深挖简历、练习应答的求职者。
- **能做什么**：从面试官视角逐题拷问你的简历，你先回答，它再给改进建议和参考说法；你把真实细节补充进去，它会帮你打磨成更经得起追问的版本。
- **怎么用**：在对话里说「**模拟面试，深挖我的简历**」。

### 3. 看懂一家公司靠什么赚钱 —— 商业洞察

- **给谁用**：想学商业逻辑、想读懂招股书和年报的财务人、投资人或学生。
- **能做什么**：你报一个公司名或行业，它会去查公开的招股书、年报等材料，用大白话拆解它的商业模式、赚钱方式、竞争位置和主要风险。
- **怎么用**：在对话里说「**分析一下 XX 公司的招股书**」。

### 4. 找到一个能写、能答辩、还能帮找工作的论文题目 —— 论文选题

> 这一项，主要是为 **商科、财经、经管类毕业生和 MBA 学生** 准备的，尤其是要写 **案例分析论文** 的同学。

- **给谁用**：本科、硕士、专硕、学硕的商科/财经/经管学生，以及 MBA 同学——不管你是还没想好题目，还是已经有了公司想找题目，都可以用。
- **能做什么**：
  - 结合你的**学校、专业、培养类型和论文要求**，从真实的上市公司案例里，帮你找出有数据、有证据、写得完的题目；
  - 每个题目都讲清楚：**研究什么、需要哪些资料、难度多大、答辩风险在哪**；
  - 你如果连公司都没想好，它会先给你推荐几家候选公司，你挑一家再往下走。
- **学术 + 找工作的双重价值**：
  - **学术上**：题目来自真实公司的真实经营问题，有公开年报、招股书作证据，能写、能算、能答辩，不会停在空喊口号。
  - **求职上**：案例论文本身就是你的「实战作品」。面试时你能讲出「我看过一家真实公司，懂它的业务、财务和决策」，比只会背理论更有说服力；题目里的商业故事，也可以直接变成你面试时的公司分析案例。
- **怎么用**：在对话里说「**帮我选论文题目**」，告诉它你的专业、学历层次，如果有想研究的公司也一并告诉它。它会用大白话跟你一步步确认，不用你懂任何术语。

## 开始用很简单

1. 让你常用的 AI 助手装上 GXG（装一次，以后一直能用；安装方法见下方「安装」）。
2. 装好后，直接在对话里用大白话提问就行，比如：
   - 「帮我分析这份简历和这个岗位匹配吗？」
   - 「我下周面试这家公司，帮我准备一下」
   - 「分析一下这家公司的招股书，它靠什么赚钱？」
   - 「帮我选个论文题目，我学工商管理，是本科」
3. 材料不够时，它会直接告诉你缺什么、缺了会影响哪些判断，不会瞎猜。

## 关于「GXG 资料」

如果你过去买过观星哥的咨询、简历或面试服务，可以把已有的资料继续交给 GXG 用，包括：

1. **咨询录音转写文本**：咨询、辅导、复盘过程的记录。
2. **简历及面试服务的全套交付材料**：人设文档、简历诊断与修改、岗位分析、人岗匹配、面试问题清单、辅导记录、参考话术等。

这些资料不是必须的，但你提供了，GXG 就能复用你已经确认过的经历和能力，减少重复沟通，结果也更贴合你本人。

## 安装

> 如果你不想自己动手装，也可以直接联系观星哥（文末有微信），或让身边懂电脑的朋友帮忙。下面两条命令只会在你的电脑里安装一个文件夹，不会影响其他东西。

**Mac / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/YFzh1995/GXG/main/install.sh | bash
```

**Windows**

```powershell
iwr -Uri https://raw.githubusercontent.com/YFzh1995/GXG/main/install.ps1 -OutFile $env:TEMP\gxg-install.ps1
& $env:TEMP\gxg-install.ps1
Remove-Item $env:TEMP\gxg-install.ps1
```

安装完成后，**新开一个对话**，输入 `@gxg` 就可以开始。
